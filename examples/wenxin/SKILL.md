# 文心雕龍 · 可执行方法论

> 每条结论后的方括号如 `[c32p001]` 指向原书段落，可用
> `dz.py show work/wenxin c32p001` 回查原文。

## 这本书解决什么问题

它处理的是「一篇文字从立意到成篇，哪几个环节会塌」。给的印象不靠灵感，靠判据：先看情与体配不配，再看三准立没立，再把字句裁一遍，最后用六观冷读。它假设你手上已经有真实稿子——所有判据都要对着自己的稿子量，没有稿子就无处落地。

## 核心模型

### 模型一：因情立体，即体成势

- **一句话**：先定「这篇要说什么」，由情决定用哪种文体；文体一落定，写法就跟着落定。顺序反过来，写出来的是别扭。
- **原文依据**：[c30p000]（因情立体，即体成势）
- **什么时候用**：题目有了但形式还没定的时候。
- **什么时候失效**：文体是外部规定死的（公文、合同、说明书、平台指定格式）。此时没有选体的自由，直接照该文体的规范写——原书把这类归为「章表奏议，则准的乎典雅」[c30p003]，声调是体裁给的，不是选出来的。

### 模型二：三准（设情位体 → 酌事取类 → 撮辞举要）

- **一句话**：动笔前先立三条准绳，且必须按这个顺序：先定情感基调与体裁，再定要用哪些材料与事例，最后才决定用什么词。挑词放在最后。
- **原文依据**：[c32p001]（草创鸿笔，先标三准：履端于始，则设情以位体）
- **什么时候用**：写有结构的稿子，尤其是超过一千字的。
- **什么时候失效**：篇幅短到一两句的文本（标题、口号、单条文案）——立三准的工夫超过写本身（个人补充）。原书给的伸缩判据「引而申之，则两句敷为一章，约以贯之，则一章删成两句」[c32p002] 也是按可伸缩的篇幅说的。

### 模型三：风骨——内容立得住，表达才有劲

- **一句话**：一篇文字要同时有两样：骨（义理站得住，删掉修饰还剩东西）和风（有感染力，能推得动读者）。缺骨则软，缺风则干。
- **原文依据**：[c28p000]（风为化感之本源，志气之符契）、[c28p002]（确乎正式，使文明以健，则风清骨峻）
- **什么时候用**：判断一篇稿子「软不软」——读者读完有没有被推动。
- **什么时候失效**：记录、说明、流程文字不以说服为目的；清单式的技术文档也不吃这一套。原书把这些另列一档 [c30p003]。

### 模型四：六观——评估任何稿子的六个观测点

- **一句话**：读一篇文字，按六个体检项过一遍：一观位体（结构是否得当）、二观置辞（措辞）、三观通变（有无继承与变化）、四观奇正（新奇的度）、五观事义（材料用典）、六观宫商（音调节奏）。
- **原文依据**：[c48p003]（先标六观）
- **什么时候用**：审稿、改稿、自查。
- **什么时候失效**：用来自评会失真。原书自己说「知多偏好，人莫圆该」[c48p002]——人各有偏好，很难全面。所以六观要么给别人用，要么隔一段时间冷读。

### 模型五：通变——体有常，数无方

- **一句话**：文体的规矩是稳定的，具体写法必须变。变的分寸落在「质」与「文」之间斟酌，变过头就变成另一个东西了。
- **原文依据**：[c29p000]（设文之体有常，变文之数无方）、[c29p002]（青生于蓝，绛生于蒨，虽逾本色，不能复化）
- **什么时候用**：想跟风改风格、或想做出新意的时候。
- **什么时候失效**：只对需要被反复阅读的文本成立。当「新」本身就是目的（梗、噱头），权衡质文这套用不上——而且反着写有一条底线：原书说「文反正为乏，辞反正为奇」[c30p005]，为反而反，内容就空了。

## 可执行流程

**Step 1 · 定情与体**
- 做什么：用一句话写清「这篇为什么非写不可」，再据此选体裁。
- 判据：这句话能被人复述，且它确实决定了体裁选择 [c30p000]。
- 常见错误：先想形式（做几页、配什么图、几个镜头）再倒推要说什么。

**Step 2 · 立三准**
- 做什么：按顺序写下三行——①情感基调与体裁 ②要用的核心事例与材料 ③关键用词与概念。
- 判据：写完能回答「每一段服务的是哪一条准」[c32p001]。
- 常见错误：一上来就抠词。原书说「凡思绪初发，辞采苦杂，心非权衡，势必轻重」[c32p001]——心里没有权衡标准，轻重就失调。

**Step 3 · 练字（四避）**
- 做什么：过一遍字面，四条：一避诡异、二省联边、三权重出、四调单复 [c39p004]。
- 判据：连续三句里同一个字出现不超过三次——原书给的线是「可至三接，三接之外，其字林乎」[c39p004]。
- 常见错误：为求新造拗口表达。原书说「吃文为患，生于好诡，逐新趣异，故喉唇纠纷」[c33p001]。

**Step 4 · 鎔裁**
- 做什么：两件事分开做——鎔是理纲领，裁是去芜秽 [c32p000]。
- 判据：一段话能压成两句而意思不丢，它就是冗余 [c32p002]；反过来，如果纲领理不顺，删字救不了。
- 常见错误：只删字不理纲领。原书把两者并列：「裁则芜秽不生，鎔则纲领昭畅」[c32p000]。

**Step 5 · 附会（首尾相援）**
- 做什么：检查主干与分支的关系——「整派者依源，理枝者循干」[c43p001]。
- 判据：全部材料都能挂回同一个纲领上，「使杂而不越」[c43p000]；结尾与开头互相支撑 [c43p004]。
- 常见错误：按材料自身的顺序堆叠，而不是按你的纲领排。「驱万涂于同归，贞百虑于一致」[c43p001]。

**Step 6 · 六观冷读**
- 做什么：隔开一段时间，按六观逐项过一遍 [c48p003]。
- 判据：从字面能还原出你当初的情，才算通——「缀文者情动而辞发，观文者披文以入情」[c48p004]。
- 常见错误：在自己偏爱的一处反复打磨，其余五观没看 [c48p002]。

## 判断清单

- [ ] 一句话说得清这篇为什么非写不可吗？ [c30p000]
- [ ] 体裁是被规定的还是选出来的？被规定的话，有没有照该体裁的规范写？ [c30p003]
- [ ] 情真、辞巧，两样都占了吗？原书的标准是「情欲信，辞欲巧」[c02p000]。
- [ ] 每一段能指回某一条「准」吗？ [c32p001]
- [ ] 有没有那种删掉一半也不丢意思的句子？ [c32p002]
- [ ] 连续三句里同一个字出现三次以上了吗？ [c39p004]
- [ ] 有没有为求新而拗口的地方？ [c33p001]
- [ ] 用典和比喻贴切吗？标准是「比类虽繁，以切至为贵，若刻鹄类鹜，则无所取焉」[c36p002]。
- [ ] 说理类文字，是把事说清楚了，还是绕？原书说「事以明核为美，不以环隐为奇」[c24p002]。
- [ ] 句序章序顺不顺？「搜句忌于颠倒，裁章贵于顺序」[c34p002]。
- [ ] 留白够不够？「隐以复意为工」——意思是生在字面之外的 [c40p001]。
- [ ] 主干是什么，所有分支都挂在它上面吗？ [c43p001]
- [ ] 六观逐项过完了吗？ [c48p003]
- [ ] 从字面能不能还原出当初的情？ [c48p004]

## 反例与失败模式

| 错误做法 | 为什么错 | 原文依据 |
|---|---|---|
| 用词与对象身份不配 | 陈思《武帝诔》用「尊灵永蛰」、《明帝颂》用「圣体浮轻」；「浮轻」近蝴蝶、「永蛰」近昆虫，施于尊者不当 | [c41p000] |
| 把礼制用语下移 | 潘岳写内兄用《礼》文的「感口泽」、写幼子用「心如疑」；辞虽可哀，义已失当 | [c41p000] |
| 比拟失伦 | 崔瑗诔李公比作黄帝虞舜，向秀赋嵇生比作李斯——「拟人必于其伦」 | [c41p001] |
| 为文造情 | 心里本无郁结，靠夸饰沽名；与「为情而造文」相反，结果是淫丽烦滥 | [c31p004] |
| 打着新奇旗号穿凿 | 「厌黩旧式，故穿凿取新」，看着难，其实只是反正 | [c30p005] |
| 本钱不够就抛旧规矩 | 「骨采未圆，风辞未练，而跨略旧规，驰骛新作，虽获巧意，危败亦多」 | [c28p002] |
| 比喻不贴切 | 「刻鹄类鹜」——想画天鹅画成鸭子，等于没用 | [c36p002] |
| 只顾外在音律 | 「外听易为察，内听难为聪」，念着顺不等于内在节奏对 | [c33p000] |
| 只顾形式不顾实质 | 「文采所以饰言，而辩丽本于情性」；「经正而后纬成，理定而后辞畅」，顺序反了则辞不畅 | [c31p003] |
| 把文章当纯粹技艺 | 原书说「文心」即「为文之用心」，去圣久远而「辞人爱奇，言贵浮诡」，离本越远越滥 | [c50p001] |

## 边界

- 原书讨论的是骈俪时代的书面语。声律、四对（「言对为易，事对为难」[c35p001]）、联边这类讲究，在现代中文写作里相当一部分不是刚需。现代写作可以直接取「避诡异」「权重出」两条，其余按需 [c39p004]。
- 六观用于自评会失真，这是原书自己承认的：「知多偏好，人莫圆该」[c48p002]。
- 「因情立体」只在你有选体自由时成立。格式被规定死的场合没有这个自由度，此时声调由体裁给 [c30p003]。
- 文风受时代牵引：「歌谣文理，与世推移，风动于上，而波震于下者也」[c45p000]。所以这套判据能给的是下限，不是风格上限。
- 材料来源是 ctext 的繁体本，且本材料包按关键句压缩、长段落截到 300 字（见 `prep/`）。需要完整上下文时用 `dz.py show` 回查，不要凭压缩句下判断。
- 原书评的是有修辞追求的书面文字，不覆盖口语、对话、口播稿的口语节奏问题——那类文本的判据书里没有（个人补充）。
- 书里对「写多少」没有量化标准，只给了伸缩原则 [c32p002]。篇幅决策仍需自己定（个人补充）。
